👋 Hi, I'm Amit, a B.Tech graduate in Electronics and Communication Engineering from NIT Kurukshetra (2024).

I’m passionate about software development, with a focus on system design, clean architecture, and scalable full-stack solutions.

Over time, I’ve worked across multiple layers of development:

- 💻 Full Stack Web Development: Built responsive web apps and integrated secure payment systems during my internships at AIDEOA and Raja Software Labs.

- 🧠 AI & Data Projects: Developed Shopping Trend Analysis using Python, pandas, and data visualization to extract actionable customer insights.

- ⚙️ System Design (LLD Focus): Designed DishScoutApp, a food-ordering system in C++ following SOLID principles and key design patterns (Factory, Strategy, Facade).

Currently, I’m deepening my understanding of system design, exploring both Low-Level Design (LLD) and High-Level Design (HLD) with emphasis on:

- Class design and object modeling

- Applying SOLID & GRASP principles

- Design patterns for scalability

- Real-world architectural patterns

I enjoy breaking down complex systems into clean, modular components and documenting my learning through projects and GitHub repos.

Tech Stack: C++, JavaScript, React, Next.js, Node.js, Express.js, MongoDB, Python

🚀 Always designing. Always building. Always learning.

## 🧱 System Design Work  

### 🍽️ **DishScoutApp – Food Ordering System (C++)**
A **Low-Level System Design (LLD)** project showcasing real-world architecture and SOLID principles.

**Highlights:**  
- Modular C++ codebase structured with `.h` header files  
- Implemented **Strategy**, **Factory**, and **Facade** design patterns  
- Separate layers for `models`, `managers`, `strategies`, and `services`  
- Extensible structure allowing easy addition of payment or order types  

> 🧩 This project reflects real-world architecture for scalable applications — bridging the gap between coding and design thinking.
